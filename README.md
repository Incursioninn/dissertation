## Обучение клавиатурным действиям

Программу можно обучить макросам

```text
компьютер научись действию следующее окно
```

Ассистент напишет что вот сейчас надо жать

```text
Alt + Tab
```

Затем сказать готово

```text
компьютер готово
```

После этого действие улетит в `data/actions.json` как `macro`

```text
компьютер открой следующее окно
```

Действия мышки пока не добавил, там тяжело

## Обучение неизвестного глагола и неизвестной программы

Ассистент может обучаться неизвестной команде

```text
стартани игру
```

Если он не знает ни слово `стартани`, ни цель `игру`, он запускает обучение

1. считает первое как действие
2. считает оставшуюся часть названием новой цели (проблема, надо будет множественные сценарии)
3. просит открыть нужную программу вручную
4. после команды `запомни` получает путь активного `.exe`
5. сохраняет цель в `actions.json`
6. сохраняет новый глагол в `synonyms.json`

```json
"learned_verbs": {
  "стартани": "open_target"
}
```

После этого должны работать команды (не только они я еще подтянул морфологию, склонения разные тоже должны работать)

```text
стартани игру
стартани браузер
стартани телеграм
```
